## Como usar

1. Abra uma aula na pasta [`aulas/`](./aulas/).
2. Leia os pré-requisitos do `README.md` daquela aula.
3. Execute os exemplos pelos comandos apresentados.
4. Consulte as referências para aprofundar o tema.

## Princípios

- exemplos pequenos e executáveis;
- explicações proporcionais ao nível do tema;
- uso real, limites e erros comuns;
- referências oficiais e fontes conceituadas;
- nenhum segredo ou credencial no repositório.
